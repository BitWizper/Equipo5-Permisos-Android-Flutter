# Permisos Bluetooth

Aplicacion Flutter para Android que solicita los permisos Bluetooth `Scan` y
`Connect` y muestra su estado. No escanea, empareja ni conecta dispositivos.

## Ejecutar

Conecta un telefono Android con la depuracion USB activada y ejecuta:

```shell
flutter pub get
flutter run
```

En la pantalla, pulsa **Solicitar permisos** para mostrar la solicitud de
permisos del sistema.
